# टेलीप्रॉम्प्टर

[Català](README.md) · [Español](README.es.md) · [English](README.en.md) · [Français](README.fr.md) · [中文](README.zh.md) · **हिन्दी** · [العربية](README.ar.md)

---

हल्का वेब टेलीप्रॉम्प्टर ऐप जिसमें वीडियो रिकॉर्डिंग, डुअल-स्क्रीन सपोर्ट और **7 भाषाओं** में अनुवादित इंटरफ़ेस है।

> केवल शुद्ध HTML + CSS + JavaScript के साथ काम करता है — `npm` नहीं, build step नहीं, कोई dependency नहीं।

---

## विशेषताएँ

- स्क्रिप्ट एडिटर के साथ रीयल-टाइम अवधि अनुमान
- गति नियंत्रण (60–200 WPM) और टेक्स्ट का आकार (28–96 px)
- दो दृश्य मोड: कैमरा पृष्ठभूमि के रूप में, या टेलीप्रॉम्प्टर के साथ छोटा खींचने योग्य प्रीव्यू
- `MediaRecorder` से वीडियो रिकॉर्डिंग और सीधे `.webm` डाउनलोड
- **डुअल-स्क्रीन** मोड: मुख्य विंडो में स्क्रिप्ट, दूसरी विंडो में कैमरा/टेलीप्रॉम्प्टर
- समेटने योग्य साइडबार
- **पूर्ण इंटरनेशनलाइज़ेशन** JSON फ़ाइलों के साथ (RTL समर्थन सहित)

## आवश्यकताएँ

- एक आधुनिक ब्राउज़र (Chrome 90+, Edge 90+, Firefox 90+, Safari 15+)
- **एक स्थानीय HTTP सर्वर** (`file://` से फ़ाइल खोलने पर कैमरा काम नहीं करता)
- कैमरा और माइक्रोफ़ोन (रिकॉर्डिंग के लिए)

## ऐप कैसे चलाएँ

ब्राउज़र को कैमरे की अनुमति देने के लिए ऐप को **स्थानीय सर्वर की आवश्यकता** है। निम्न में से कोई एक विकल्प चुनें:

### विकल्प 1 — Python (अनुशंसित, कई सिस्टमों पर पहले से इंस्टॉल)

```bash
cd Teleprompter
python -m http.server 8000
```

फिर ब्राउज़र में [http://localhost:8000](http://localhost:8000) खोलें।

### विकल्प 2 — Node.js

```bash
cd Teleprompter
npx serve .
```

या:

```bash
npx http-server -p 8000
```

### विकल्प 3 — PHP

```bash
cd Teleprompter
php -S localhost:8000
```

### विकल्प 4 — VS Code / Cursor

**Live Server** एक्सटेंशन इंस्टॉल करें और `index.html` पर राइट-क्लिक करें → *Open with Live Server*।

## भाषा कैसे बदलें

### इंटरफ़ेस से
1. साइडबार खोलें।
2. **पढ़ने की सेटिंग्स** कार्ड में **भाषा** अनुभाग पर जाएँ।
3. ड्रॉपडाउन से भाषा चुनें। इंटरफ़ेस तुरंत अनुवादित हो जाता है।

### कंसोल से भाषा सेट करें
ब्राउज़र के DevTools कंसोल में:

```js
window.i18n.setLocale('en');   // ca, es, en, fr, zh, hi, ar
```

### रीसेट
स्वचालित पहचान बहाल करने के लिए:

```js
localStorage.removeItem('teleprompter_locale');
location.reload();
```

## नई भाषा जोड़ें

1. किसी मौजूदा फ़ाइल को कॉपी करें, जैसे `locales/en.json`, और `locales/<कोड>.json` के रूप में सहेजें।
2. सभी मानों का अनुवाद करें (कुंजियाँ और प्लेसहोल्डर `{{count}}`, `{{wpm}}`, `{{size}}` बनाए रखें)।
3. यदि यह RTL भाषा है, तो JSON रूट पर `"dir": "rtl"` जोड़ें।
4. `i18n.js` संपादित करें और कोड को `AVAILABLE_LOCALES` सूची में जोड़ें।

जर्मन के लिए उदाहरण:

```js
const AVAILABLE_LOCALES = ['ca', 'es', 'en', 'fr', 'zh', 'hi', 'ar', 'de'];
```

भाषा चयनकर्ता इस सूची और प्रत्येक JSON के `languageName` फ़ील्ड से स्वचालित रूप से भरा जाता है।

## ब्राउज़र अनुमतियाँ

पहली बार रिकॉर्डिंग शुरू करने पर ब्राउज़र **कैमरा** और **माइक्रोफ़ोन** की अनुमति माँगेगा। यदि आप अस्वीकार करते हैं:

- पता बार में लॉक आइकन पर क्लिक करें।
- इस साइट के लिए `कैमरा` और `माइक्रोफ़ोन` की अनुमति दें।
- पेज को पुनः लोड करें।
