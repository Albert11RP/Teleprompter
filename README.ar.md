# ملقّن

[Català](README.md) · [Español](README.es.md) · [English](README.en.md) · [Français](README.fr.md) · [中文](README.zh.md) · [हिन्दी](README.hi.md) · **العربية**

---

تطبيق ويب خفيف للملقّن مع تسجيل الفيديو، ودعم الشاشة المزدوجة، وواجهة مترجمة إلى **7 لغات**.

> يعمل فقط باستخدام HTML + CSS + JavaScript صرف — بدون `npm`، وبدون خطوة بناء، وبدون أي تبعيات.

---

## الميزات

- محرّر نص مع تقدير المدة في الوقت الفعلي
- التحكم في السرعة (60–200 ك/د) وحجم النص (28–96 بكسل)
- وضعان للعرض: الكاميرا كخلفية، أو الملقّن مع معاينة صغيرة قابلة للسحب
- تسجيل الفيديو باستخدام `MediaRecorder` وتنزيل مباشر بصيغة `.webm`
- وضع **الشاشة المزدوجة**: النص في النافذة الرئيسية والكاميرا/الملقّن في نافذة ثانية
- شريط جانبي قابل للطي
- **تعريب كامل** باستخدام ملفات JSON (مع دعم RTL)

## المتطلبات

- متصفح حديث (Chrome 90+ أو Edge 90+ أو Firefox 90+ أو Safari 15+)
- **خادم HTTP محلي** (لا تعمل الكاميرا عند فتح الملف عبر `file://`)
- كاميرا وميكروفون (للتسجيل)

## كيفية تشغيل التطبيق

يحتاج التطبيق إلى **خادم محلي** كي يسمح المتصفح بالوصول إلى الكاميرا. اختر إحدى الطرق التالية:

### الخيار 1 — Python (مُستحسن، مُثبّت مسبقًا على كثير من الأنظمة)

```bash
cd Teleprompter
python -m http.server 8000
```

ثم افتح [http://localhost:8000](http://localhost:8000) في المتصفح.

### الخيار 2 — Node.js

```bash
cd Teleprompter
npx serve .
```

أو:

```bash
npx http-server -p 8000
```

### الخيار 3 — PHP

```bash
cd Teleprompter
php -S localhost:8000
```

### الخيار 4 — VS Code / Cursor

ثبّت إضافة **Live Server** ثم انقر بزر الفأرة الأيمن على `index.html` ← *Open with Live Server*.

## كيفية تغيير اللغة

### من الواجهة
1. افتح الشريط الجانبي.
2. في بطاقة **إعدادات القراءة**، اذهب إلى قسم **اللغة**.
3. اختر لغة من القائمة المنسدلة. تُترجم الواجهة فورًا.

### فرض لغة عبر وحدة التحكم
في وحدة تحكم المتصفح (DevTools):

```js
window.i18n.setLocale('en');   // ca, es, en, fr, zh, hi, ar
```

### إعادة التعيين
لاستعادة الاكتشاف التلقائي:

```js
localStorage.removeItem('teleprompter_locale');
location.reload();
```

## إضافة لغة جديدة

1. انسخ ملفًا موجودًا، مثل `locales/en.json`، باسم `locales/<الرمز>.json`.
2. ترجم جميع القيم (مع الحفاظ على المفاتيح والعلامات `{{count}}` و`{{wpm}}` و`{{size}}`).
3. إن كانت اللغة من اليمين إلى اليسار (RTL)، أضف `"dir": "rtl"` في جذر JSON.
4. عدّل `i18n.js` وأضف الرمز إلى قائمة `AVAILABLE_LOCALES`.

مثال للألمانية:

```js
const AVAILABLE_LOCALES = ['ca', 'es', 'en', 'fr', 'zh', 'hi', 'ar', 'de'];
```

يُملأ منتقي اللغة تلقائيًا اعتمادًا على هذه القائمة وعلى حقل `languageName` لكل JSON.
